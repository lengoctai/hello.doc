\# Contributing



\## Báo lỗi



Nếu phát hiện lỗi, hãy tạo Issue trên GitHub và mô tả rõ lỗi gặp phải.



\## Đề xuất chức năng



Tạo Issue và mô tả chức năng muốn bổ sung.



\## Pull Request



1\. Tạo branch mới.

2\. Thực hiện thay đổi.

3\. Kiểm tra chương trình.

4\. Commit thay đổi.

5\. Push branch lên GitHub.

6\. Tạo Pull Request.



Ví dụ:



git checkout -b feature/new-function

git add .

git commit -m "Add new function"

git push origin feature/new-function
